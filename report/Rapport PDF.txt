Page 1 — Introduction
Mini Store Manager est une application web permettant à un petit commerce de gérer ses produits, clients, commandes et statistiques de vente.
Le projet combine :

conception d’une base SQLite,

SQL avancé,

développement Flask,

documentation technique.

J’ai choisi Python + Flask pour sa simplicité et sa compatibilité avec SQLite.

Page 5 — SQL avancé
Exemple 1 — Produits jamais commandés
sql
SELECT p.*
FROM Product p
LEFT JOIN OrderItem oi ON oi.product_id = p.id
WHERE oi.product_id IS NULL;
Exemple 2 — Commandes au-dessus de la moyenne
sql
WITH order_totals AS (
    SELECT o.id, SUM(oi.quantity * oi.unit_price) AS total
    FROM CustomerOrder o
    LEFT JOIN OrderItem oi ON oi.order_id = o.id
    GROUP BY o.id
),
avg_value AS (
    SELECT AVG(total) AS avg FROM order_totals
)
SELECT ot.*
FROM order_totals ot, avg_value av
WHERE ot.total > av.avg;
